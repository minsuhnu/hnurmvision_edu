# 第四讲算法与学习记录

## 位姿、相机和坐标约定

位姿同时包含参考点的位置与物体坐标轴的朝向。OpenCV 光学系为 x 右、y 下、z 前，PnP 输出满足 `X_C = R_C_M X_M + t_C_M`，方向是物体到相机。旋转向量通过 Rodrigues 公式转换为旋转矩阵；四元数适合连续姿态计算，欧拉角更直观，但必须同时说明轴、内外旋和顺序，在奇异姿态附近会发生万向节锁。[OpenCV 位姿文档](https://docs.opencv.org/4.x/d5/d1f/calib3d_solvePnP.html) 给出了该变换约定。

稳定系中的点为 `p_W = R_W_C p_C + t_W_C`。主程序复用相机到云台外参和 IMU 四元数。验收程序使用采集记录中的实际相机变换作为自车位姿输入，W 轴对应 `(Bevy X, -Bevy Z, Bevy Y)`，原点固定在会话首帧相机光心；下文的 W 均指这个固定参考系。

参考点转换为 `T_C_CENTER = T_C_M × inverse(T_CENTER_M)`。矩阵的乘法顺序不能颠倒。齐次坐标用末项 1 表示点、0 表示向量，将旋转和平移统一为矩阵运算；缩放属于仿射变换，带缩放的 glTF 网格矩阵不能直接当作旋转矩阵。

相机模型用内参 K 将归一化平面的 `(X/Z,Y/Z)` 映射为像素坐标。畸变系数依次为 `[k1,k2,p1,p2,k3]`，分别描述径向与切向畸变。本仿真为理想透视渲染，D 为零；真实相机仍需标定。张正友棋盘格标定使用多个视角的已知尺寸角点，联合求 K、D 和外参，并检查重投影误差。低重投影误差还不足以证明物点尺寸、角点身份或绝对位姿正确。

镜头决定视野、焦距与进光量，传感器将光转换为电信号，处理器完成去噪、色彩等处理。分辨率与帧率影响采样；曝光影响亮度和运动模糊；增益同时放大信号与噪声。这些参数都会改变阈值灯条轮廓，进而影响 PnP，而不只是影响显示效果。

## PnP 与真实观测模型

第三讲的四点是二维灯条最小外接矩形长轴端点，并非四个隐藏 MARKER 网格顶点。`configs/lesson04.yaml` 用资产灯条 AABB 的虚拟中心线端点初始化 IPPE；`lesson04_lamp_meshes.json` 保存由同一 GLB 几何转换得到的实际灯条顶点。大小板分别配置，尺寸和坐标均由对应资产计算。

原有数值内核继续检查输入、退化、平面性、有限值、正深度和重投影误差，保留两个 IPPE 候选。近似观测单独记录输入来源；`correspondence_verified` 表示固定物点对应，`physical_accuracy_verified` 留给独立真值验证。在此之后，网格观测修正将每条灯的真实网格投影，求与第三讲相同定义的 minAreaRect 长轴端点，以观测残差优化位姿，同时使用直立车体、15°安装角的资产约束。该约束不适用于任意倾斜车体，未知安装时应关闭或重新配置。

修正器对两个 PnP 初值分别进行局部优化，比较观测代价；不用目标真实位姿选择分支。原始 PnP 候选 CSV 与最终 CENTER 位姿 CSV 分别保存。局部优化和物理先验减少了本场景偏差，并未证明全局唯一解。

## 选板与跟踪

流程为图像检测→选板→该板 PnP→坐标变换→跨帧状态更新。初次按实际分辨率中心选板；锁定后将上一状态的匀速预测回投到当前相机，结合类别与大小板一致性进行门限关联。每帧只对选中的板执行 IPPE。

状态为 LOST、DETECTING、TRACKING、TEMP_LOST。连续 3 次观测建立跟踪；短时丢失保留关联历史，但不把外推当新观测输出。丢失超过 0.3s 或帧间隔超过 0.4s 时重置，重新发现后不复用旧速度。重复、回退和无效时间戳、非有限值、无效外参及速度突变都被处理。当前网格模型适用于 OpenCV 和 Hybrid 的灯条几何；纯 Pose 关键点的对应关系尚未验证。

## 匀速预测与独立验收

基础差分为 `v=(p_now-p_prev)/(t_now-t_prev)`；实现仍用 CV 模型，通过最近约 0.2s 的真实时间样本拟合 `p(t)=a+vt` 以抑制 PnP 噪声，两点时即退化为差分。预测为 `p_future=p_now+v*n/1000`，n 默认 250ms。该预测不包含通信、云台或子弹飞行补偿。

预测点在稳定三维系计算，逆变换到当前相机后，用同一模型与标定投影为蓝框；当前检测为绿框和绿色角点。预测记录包含发出时间、到期时间、目标 ID、场景、跟踪代次和坐标。到期后在同 ID 的前后两条真实记录间线性插值，不阻塞主循环。超过 0.3s 的真值间隔、换场景、缺失 ID 均不计入有效比较，结束时未到期记录单列。

位置误差为三维欧氏距离，姿态误差为 `acos(clamp((trace(R_gt^T R_est)-1)/2,-1,1))`。同步核验结果另存 `validation.json`，包括 PNG/JSON 哈希、原 ROS 像素、运动投影和预测时间检查，原始元数据保持不变。结论限于实际检查的采集序列。
